# מחולל מכתבי התרעה משפטיים אישיים – עובדי בנק הפועלים בע״מ

מערכת עזר טכנולוגית לעובדי בנק הפועלים. האפליקציה מאפשרת לכל עובד/ת, מהנייד או מהמחשב:
למלא פרטים אישיים, לסמן את ההפרות והפגיעות הרלוונטיות, לחתום דיגיטלית על המסך,
ולהפיק ולשגר בלחיצת כפתור מכתב התרעה משפטי רשמי, מנומק וחתום (PDF מצורף + גוף מייל מעוצב)
לגורמי ההנהלה, הפיקוח והרגולציה.

> מערכת עצמאית שאינה מטעם בנק הפועלים בע״מ. כלי עזר טכני בלבד, ואינו ייעוץ משפטי.

## מבנה הפרויקט

| קובץ | תפקיד |
| :--- | :--- |
| `index.html` | האפליקציה המלאה בקובץ יחיד: Tailwind CSS, jsPDF ו-html2pdf.js נטענים מ-CDN |
| `google-apps-script/Code.gs` | שרת שיגור אישי ב-Google Apps Script: יצירת טיוטה או שליחה מחשבון ה-Gmail של העובד/ת, עם ה-PDF המצורף |
| `api/send-notice.js` | פונקציית Serverless ל-Vercel: שליחה דרך Resend או SMTP (אופציונלי) |
| `tests/acceptance.cjs` | בדיקות קבלה אוטומטיות ב-Playwright |

## הפעלה מהירה

- **מקומית:** לפתוח את `index.html` בדפדפן, או להריץ `npm start` ולגלוש ל-`http://localhost:3000`.
- **אירוח סטטי** (GitHub Pages / Netlify / Cloudflare Pages): להעלות את `index.html`. כל השאר רץ בדפדפן.
- **Vercel:** לייבא את המאגר. `index.html` מוגש כדף הבית ו-`api/send-notice.js` הופך ל-`/api/send-notice`.

## אשף 5 השלבים

1. **פרטים אישיים:** שם, ת.ז. (כולל בדיקת ספרת ביקורת), תפקיד, מחוז, סניף, ותק ותאריך. כאן גם משטח החתימה הדיגיטלי (מגע ועכבר) והצהרת האמת, שחובה לסמן אותה.
2. **מכותבים:** 7 הגופים הרשמיים (2 ב-To ו-5 ב-CC), ושדה חופשי למכותב ישיר נוסף.
3. **עומסים ופגיעה בתנאים:** 15 סעיפים, חלקם עם שדה פירוט אישי, ושורות שעות דינמיות.
4. **בריאות, נפש וגוף:** 7 סעיפי נזק.
5. **הפקה ושיגור:** תצוגת A4 חיה ו-4 שכבות שיגור (פירוט בהמשך).

הטיוטה נשמרת אוטומטית ב-`localStorage` (מפתח `poalim_legal_notice_draft_v1`), כולל החתימה,
ומשוחזרת בטעינה הבאה. הנתונים לא יוצאים מהמכשיר עד שהמשתמש/ת מבצע/ת שיגור.

## 4 שכבות השיגור

| שכבה | מה קורה |
| :--- | :--- |
| א׳ – ענן | `POST` עם `{ mode, to, cc, subject, textBody, htmlBody, pdfBase64, filename }`. השרת יוצר טיוטה ב-Gmail או שולח מיד. לפני שליחה מיידית מוצג אישור נוסף. |
| ב׳ – שיתוף Native | בכניסה לשלב 5 ה-PDF החתום מופק ברקע (`cachedPdfFile`), כך ש-`navigator.share({ files })` נקרא מיד בלחיצה. רשימת הנמענים מועתקת ללוח. |
| ג׳ – לקוח מייל | `mailto:` קומפקטי (פחות מ-850 תווים) עם `target="_top"`, Intent ייעודי ל-Gmail באנדרואיד, וחלון כתיבה של Gmail Web למחשב. |
| ד׳ – חלונית שיגור | כל כפתור פותח מיד את `#dispatch-hub-modal`: חיווי מצב, תמונת A4 חתומה (לחיצה ארוכה לשמירה או שיתוף, גם ב-WebView חסום) ו-3 כפתורי העתקה מהירה. |

בנוסף ניתן להוריד PDF חתום, להוריד קובץ Word (`.doc` בפורמט MHTML, כולל החתימה כתמונה מוטמעת) ולהדפיס.

## הגדרת שיגור אוטומטי דרך Google Apps Script (מומלץ)

השיגור יוצא מחשבון ה-Gmail **האישי** של העובד/ת, ולכן כל עובד/ת פורס/ת עותק משלו/ה:

1. להיכנס ל-[script.google.com](https://script.google.com), ליצור **פרויקט חדש** ולהדביק את תוכן `google-apps-script/Code.gs`.
2. **מומלץ מאוד:** ⚙️ *Project Settings* ← *Script properties* ← להוסיף `NOTICE_ACCESS_TOKEN` עם קוד סודי.
3. *Deploy* ← *New deployment* ← סוג *Web app*:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
4. לאשר את הרשאות ה-Gmail ולהעתיק את כתובת ה-Web App (מסתיימת ב-`/exec`).
5. באפליקציה, בשלב 5: לפתוח כל כפתור ← ⚙️ *הגדרות שיגור בענן* ← להדביק את הכתובת ואת קוד הגישה ← *שמור*.

> ⚠️ פריסה עם *Anyone* פירושה שכל מי שמחזיק בכתובת יכול לשלוח מייל מחשבונכם. לכן חשוב להגדיר `NOTICE_ACCESS_TOKEN` ולא לשתף את הכתובת.

אפשר גם להטמיע כתובת קבועה בקוד: `APP_CONFIG.APPS_SCRIPT_URL` ב-`index.html`.

## הגדרת שיגור דרך Vercel (אופציונלי)

משתני סביבה:

| משתנה | תיאור |
| :--- | :--- |
| `MAIL_FROM` | **חובה.** כתובת השולח |
| `RESEND_API_KEY` | שליחה דרך Resend, או לחלופין: |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_SECURE` | שליחה דרך SMTP (Nodemailer) |
| `NOTICE_API_TOKEN` | מומלץ: קוד גישה שחובה לשלוח בשדה `token` |
| `ALLOWED_RECIPIENT_DOMAINS` | דומיינים מותרים לנמענים (ברירת מחדל: `poalim.co.il, labor.gov.il, boi.org.il, histadrut.org.il`) |
| `ALLOWED_ORIGIN` | מקור נוסף שמורשה לקרוא לשרת (CORS) |

השרת מגביל את הנמענים לדומיינים המורשים כדי שלא ישמש כממסר דואר פתוח. יצירת טיוטה
(`mode: 'draft'`) אינה אפשרית בשרת משותף, ולכן היא זמינה רק דרך Apps Script.
כשהאתר מאוחסן ב-Vercel, האפליקציה פונה ל-`/api/send-notice` אוטומטית, אלא אם הוגדרה כתובת אחרת.

## הפקת ה-PDF

ספריית html2canvas, שעליה מבוסס html2pdf.js, מרנדרת עברית RTL בצורה שגויה: פיסוק הפוך,
רווחים שנבלעים ומספרים בסדר הפוך. לכן מנוע ההפקה הראשי משתמש ברינדור המקורי של הדפדפן:

- המכתב מחולק לעמודי A4 לפי גובה הבלוקים, בלי לחתוך פסקה באמצע ובלי להשאיר כותרת לבד בתחתית עמוד.
- כל עמוד מצויר דרך SVG `foreignObject` עם גופני Frank Ruhl Libre ו-David Libre המוטמעים בו.
- העמודים מורכבים ל-PDF באמצעות jsPDF, עם מספור עמודים.

html2pdf.js נשאר כמנוע גיבוי לדפדפנים שאינם תומכים בשיטה זו.

## בדיקות

```bash
npm i -D playwright      # אם אינו מותקן
npm test
```

הבדיקות מכסות את רשימת הקבלה:
- אין גלישה אופקית ברוחב 360×800 באף שלב, גם עם טופס ריק וגם עם טופס מלא.
- איפוס גלילה במעבר בין שלבים.
- החתימה נקלטת ומוטמעת בתצוגת ה-A4, ב-PDF ובקובץ ה-Word.
- כל כפתור בשלב 5 פותח את החלונית בפחות מ-50ms, מעתיק ללוח ומציג את תמונת ה-A4.
- השיגור לשרת (מדומה) כולל PDF תקין, To, CC, נושא וגוף.
- הטיוטה משוחזרת מ-`localStorage`.

## פרטיות ואחריות

- כל הנתונים נשמרים במכשיר בלבד, ונשלחים רק לשרת השיגור שהמשתמש/ת הגדיר/ה, ורק בלחיצה על כפתור שיגור.
- האחריות לתוכן המכתב ולשליחתו היא של המשתמש/ת בלבד (ראו את הצהרת האמת בשלב 1).
